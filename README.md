# 塑料件材料费计算器 · 免费网页版

**一句话**：把 STEP / IGES 模型拖进浏览器 → 自动拆出每个零件，算出体积、克重和材料费。

- 没有后端，模型不上传，全部在本机浏览器里算；
- 装配体自动按实体拆成多行，每个零件可单独选材料、改单价；
- 结果给出每个零件的体积/克重/材料费 + 合计；
- **3D 预览**：拖动旋转、滚轮缩放、双击复位；点表格行高亮对应零件；
  勾「只看选中」可单独看某个零件（装配体里的小零件很有用）；
  渲染器是自己写的 Canvas 软件光栅化（约 150 行），**不依赖任何 3D 库**，离线可用；
- 预留 3 个广告位，接广告代码即可；
- 页面含 SEO 文案和 FAQ，方便被搜索到。

## 一、两种打开方式

| 你想干什么 | 用哪个文件 | 说明 |
|---|---|---|
| **自己双击就能用**（离线、拷给别人） | `双击打开_单文件版.html`（9.8 MB） | CAD 内核和示例模型都内嵌在这一个文件里，双击即可上传解析 |
| **放到网站上给别人用** | `index.html` + `vendor/` 目录 | 内核外置（7.25 MB），首次访问才下载，之后走浏览器缓存，站点更轻 |

> ⚠️ 不要直接双击 `index.html`：浏览器在 `file://` 下**禁止读取本地 WASM**，会提示"上传失败"。
> 想本地测试 `index.html`：在该目录执行 `python -m http.server 8000`，再打开 `http://localhost:8000`。

## 四、3D 预览说明

- 零件按序号自动配色，表格第一列的小圆点与 3D 里的颜色一一对应；
- 点表格任意一行 → 该零件在 3D 里变成洋红色（再点一次取消）；
- 勾选右上角「只看选中」→ 只显示那一个零件，并自动放大到合适大小；
- 拖动时自动降分辨率保证流畅，松手恢复清晰；42 零件（5.4 万三角面）实测可用；
- 「复位视角」或双击画布 = 恢复默认角度。

## 五、接广告

`index.html` 里搜"广告位 ·"，三处 `div`：

```html
<div class="ad ad-top" id="ad-top">广告位 · 顶部横幅 728×90</div>
<div class="ad ad-mid" id="ad-mid">广告位 · 300×250</div>
<div class="ad ad-bottom" id="ad-bottom">广告位 · 底部横幅 728×90</div>
```

- **Google AdSense**：填 `ADS.adsenseClient = "ca-pub-xxxx"`（脚本已写好自动加载），再把广告单元代码粘进对应 div；
- **国内联盟**（百度/360）：一般要求域名已备案，同样粘代码进去；
- **自营/CPS**（淘宝客、原料平台）：适合行业流量，转化可能更好。

注意：广告别贴着按钮（误点会被判违规）；页脚已有"本站含广告"说明。

## 六、改成你自己的

1. **升级 CTA**：搜 `要算完整成本？`，把文字/链接换成你的淘宝、闲鱼、微信二维码或桌面版下载页；
2. **材料库**：搜 `const MATERIALS`，加材料/改密度和参考价；
3. **示例模型**：替换 `demo.stp`；
4. **配色**：改开头 `:root` 的颜色变量（和桌面版猫猫主题同一套）；
5. **统计**：百度统计/GA 加到 `</head>` 前。
